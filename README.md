# lethalcompany-inb-modpack
INB Modpack vor lethalcompany

This Modpack includes funny and usefull additions for a better Lethal Company experience.

There are 3 Versions:

VR: The default actively maintained Version, which includes also the VR mods
FLAT: Includes everything VR does, but ins in Flat mode, so you can see other players move correctly
NON-VR: Includes everything despite the VR mods

There is nothing much to say then...

Have fun!
